Privacy Policy

How the current ClassHub application handles information.

Last updated: October 2026

Information stored by the classroom server

When used, ClassHub stores teacher-created announcements, material metadata, uploaded files, student-entered IDs and names, session tokens, access-session and queue state, and supporting IP address and activity timestamps. These records are stored in the configured SQLite database and local file-storage directory.

How information is used

Student IDs and session tokens identify a student session. Names appear in the classroom interface. IP addresses and timestamps support session operation. Announcements and materials are shared with joined classroom users. Teacher controls require teacher authentication.

Local and public deployments

In a local classroom deployment, the operator hosting ClassHub controls the laptop, local network, database and uploaded files. The public informational website does not need to be online for classroom operation. A public deployment may be accessible to anyone who can reach its host, so it must be configured and protected appropriately.

Retention and deletion

The classroom operator is responsible for deciding how long to retain the database and uploaded files and for deleting them when they are no longer needed. Removing a material through the teacher dashboard deletes its stored file and metadata.

External services

The application’s local interfaces do not load third-party analytics, fonts, scripts or images. Links to the developer’s portfolio and social profiles open external sites only when selected.
