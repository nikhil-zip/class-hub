CURRENT CLASSROOM TOOLS

Features built around local classroom work.

ClassHub keeps essential classroom sharing and resource access in one responsive application.

Offline-first

Core classroom use runs on a private local network without Internet access.

Local file sharing

Teachers upload supported academic files to local storage for student access.

Teacher announcements

Teachers publish and remove classroom updates; students can read them.

Student dashboard

Students join with an ID and name to browse updates, materials and session status.

Material search

Students can search material titles and filenames.

Smart access scheduling

The server manages configurable active resource sessions.

FIFO queue

When slots are full, students wait in request order.

Session countdown and cooldown

Students see their remaining session or cooldown time.

Teacher dashboard

Teachers view session, queue, materials and announcement information.

Demo simulation

Teachers can create clearly marked simulated students using the real scheduler.

Mobile-friendly interface

The student view adapts to phone screens; teacher controls are responsive.

Local storage

SQLite holds application data and the uploads directory holds actual files.

Network capacity depends on the access point and hardware. ClassHub manages application-level resource access; it does not create additional Wi-Fi capacity.
