Sharing a resource

  1. The teacher publishes an announcement or uploads a class resource.
  2. A student joins and requests access to download a material.
  3. The server checks for an active session, cooldown or available capacity.
  4. If a slot is available, access starts. Otherwise, the student joins the FIFO queue.
  5. The resource session lasts for the configured duration (90 seconds by default).
  6. After expiry, cooldown begins (180 seconds by default) and queued students can be promoted.

Announcements and normal browsing remain available during a cooldown. The timer controls application-level resource access, not the student’s Wi-Fi connection.

Capacity depends on the network

ClassHub does not create Wi-Fi or promise a specific number of connected devices. Use a local network and access point suitable for the classroom. The application scheduler helps manage limited local server and resource capacity.
