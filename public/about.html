ABOUT THE PROJECT

A classroom hub, built to work locally.

ClassHub is an offline-first web application for sharing classroom announcements and academic resources over a private local network.

What is ClassHub?

ClassHub lets a teacher run a classroom web server on a laptop or local server. Students connected to the same suitable private Wi-Fi network can open the classroom address from a phone browser to read updates and find study materials.

Why it exists

Classroom Internet connectivity can be unreliable, restricted or unavailable. When academic resources depend on a cloud service, a connection problem can make everyday sharing harder. ClassHub explores a local option for those essential classroom tasks.

A local-first philosophy

No Internet dependency for essential classroom resources. The classroom application, SQLite database and uploaded files are hosted together by the local server. The public website is informational and is not required for local classroom use.

Capacity and limitations

ClassHub is designed to operate over a private local network without requiring Internet connectivity. Classroom capacity depends on local network hardware. An application-level access scheduler can manage limited resource access, but it does not expand Wi-Fi capacity or disconnect devices from the network.
